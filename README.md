# 🛒 E-Commerce Web Scraper - SkillCraft Technology (Task 04)

A Python-based web scraping application designed to extract product information (names, prices, and ratings) from an online e-commerce platform and structure the output into a clean CSV file.

---

## ✨ Features
* **Automated HTML Parsing:** Extracts key product fields using `BeautifulSoup`.
* **Structured CSV Export:** Automatically compiles extracted details into a tidy `products.csv` file.
* **Clean Terminal Feedback:** Outputs real-time extraction logs and item counters.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** `requests`, `BeautifulSoup4`, `csv` (Built-in)
